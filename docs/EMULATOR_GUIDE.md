# Emulator Guide

Эмулятор нужен для обучения и демонстрации без доступа к личным Telegram-данным.

## Что показывать

1. Sources: единая модель Telegram/RSS/Web документов.
2. Workspace: объединение источников и поисковых признаков.
3. Evolution: сравнение baseline/current snapshots.
4. Provenance: claim связан с computation и primary documents.
5. Verification: аналитик подтверждает или отклоняет claim.
6. Acquisition: evidence gap превращается в управляемый запрос.
7. Independence: перепечатки не считаются независимыми подтверждениями.
8. Timeline: supports/updates/supersedes/contradicts.

## Проверяемость

Откройте JSON и PDF прямо из эмулятора. `/api/self-test` показывает наличие, размер и SHA-256 каждого обязательного артефакта.
